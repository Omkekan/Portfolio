Autonomous RAG Agent

Self-correcting pipeline in LangGraph with retrieval-relevance grading and automatic query rewriting.

$ run --q "what changed in v2?"

grade      0.78 >= 0.62, generate
verify     1 unsupported claim, regenerate
verify     all claims supported, answer

The problem
Standard RAG pipelines retrieve context and blindly answer. If the context doesn't contain the answer, they fail silently — straight into a hallucination.

The architecture
A LangGraph state machine. Retrieved documents are graded for relevance before generation runs. If nothing relevant turns up, the query is automatically rewritten and re-retrieved. Generated answers are checked against the retrieved context, and unsupported claims trigger a regeneration pass. A final check confirms the answer actually addresses the question. Each retry path is capped at 2 attempts; when they run out, the agent says it doesn’t have enough information instead of guessing.

Stack
LangGraph for orchestration, Qdrant (hybrid dense + sparse search) as the vector store, Ollama for local inference, RAGAS for evaluation.

Web Vuln Scanner

Risk-prioritization engine correlating 3+ security feeds (CVE, CWE, Exploit-DB), cutting vulnerability noise by an estimated 90% versus raw scanner output.

The problem
Running multiple security scanners produces overlapping, high-volume alerts. Real risks get buried under duplicate and low-priority noise.

The architecture
Correlates CVE, CWE and Exploit-DB data with scan results, then scores each finding by severity, asset criticality and public exploit availability instead of surfacing a raw combined feed. Nmap scans run asynchronously on Celery/Redis workers so the interface stays responsive.

Stack
Flask + Next.js for the app, Celery + Redis for the async pipeline, PostgreSQL for storage.
